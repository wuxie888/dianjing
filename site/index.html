02 / THE DIANJING PROCESS

先验真实，
再落最后一笔。

四道工序，先事实、后表达。每一步都有清晰输入、产物和验收标准。

01

Audit

定位真实仓库、入口、版本、许可证、素材与发布状态。

02

Position

说清用户交付什么、产品完成什么、最终得到什么。

03

Compose

构成 README、真实视觉、动效、文档和发布表面。

04

Verify

检查链接、安装、移动端、减少动态和公开产物。

03 / FOUR FINISHES

美观不是贴花，
而是分层交付。

  1. L1基础门面

    定位、README、Hero、截图、安装与治理

  2. L2动态 README

    真实操作 GIF、视频入口与静态首帧

  3. L3动态产品仓库

    Pages、响应式、高级动效与减少动态

  4. L4发布级门面

    社交预览、Release 媒体、升级排错与公开回归

04 / REAL OUTPUT, REAL REPO

漂亮，要经得起核验。

不发明功能、指标、评价或兼容性。视觉只解释真实产品，发布状态按证据表达。

✓ 仓库边界与 Git 状态

✓ 真实截图、录屏与输出

✓ 安装、首次成功与升级路径

✓ 静态首帧与减少动态

✓ 远端源码、Pages 与 Release 分开验收
